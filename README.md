AI Mario Game

AI Mario Game is a browser-based platformer inspired by the classic Mario experience. The project combines retro-style gameplay with AI concepts to create an engaging and interactive experience. Built using HTML, CSS, and JavaScript, it demonstrates game development fundamentals, responsive controls, and intelligent gameplay mechanics directly in the browser.

Live Demo:
https://karthikkrishnanj.github.io/AI-Mario-Game/

Features

Classic Mario-style platforming
AI-enhanced gameplay elements
Browser-based, no installation required
Responsive controls and smooth gameplay
Built with modern web technologies
